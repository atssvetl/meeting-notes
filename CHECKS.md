# Проверки проекта

Проверенная среда: Windows, Node.js 25.6.1, Python 3.11, FFmpeg/FFprobe и Chrome в headless-режиме. Минимальная версия Node.js проекта — 24. Linux/macOS отдельно не проверялись.

## Как воспроизвести

Из корня репозитория:

```powershell
npm ci
npm run setup:local
npm test
npm run test:ui
npm run test:ui:cloud
```

Без локальных моделей соответствующие тесты пропускаются. Для полного браузерного сценария с речью положите собственную двухминутную MP4-запись в `test-output/real-2min.mp4`. В репозитории нет пользовательских записей, расшифровок, ключей и скриншотов с содержимым встреч.

## Последний подтверждённый результат

8 ноября 2026: `npm test` — **26 тестов прошли, ошибок и пропусков нет**. `npm run test:ui` — **пройдено** на ширине 1440 и 390 px с настоящей двухминутной записью. `npm run test:ui:cloud` — **пройдено** на тех же размерах экрана.

Проверено:

- Облачный импорт: принятие ссылки фоновой задачей, состояния получения и AI-анализа, автоматическое распознавание, нормализация URL, повторная ссылка без нового задания, SHA-256 и повторный файл по другому URL без второго анализа, сохранение результата после перезапуска.
- Безопасность скачивания: запрет локальных/служебных IPv4/IPv6, недопустимых схем и портов; перенаправления, ограничения размера по заголовку и потоку, HTML вместо видео, отказ доступа и ошибки сети, очистка частичных файлов.
- Публичные ссылки Яндекс Диска: запрос API с Accept JSON, проверка ответа и адреса скачивания, отдельные ошибки 403/429/5xx. Google Drive: преобразование ссылки просмотра, сохранение resourcekey, отсутствие автоматического подтверждения предупреждения о проверке файла на вирусы. Проверки используют тестовые публичные идентификаторы, без публикации пользовательских ссылок.
- Браузерный импорт: выключенные флажки ручной загрузки не мешают автоанализу облачной записи; обновление страницы во время получения; отображение источника, повторная ссылка, понятная ошибка авторизации и запасной вариант ручной загрузки.
- Приём MP4/WebM, повреждённые и пустые файлы, отсутствие аудио, тишина и отсутствие API-ключа.
- Ручные и автоматические этапы, запрет одновременной обработки и повторного запуска завершённого этапа, сохранение состояния после перезапуска.
- Настоящее локальное распознавание русского WAV; отсутствие расхода API.
- Определение голосов на полном аудио, сохранение таймкодов через тишину и границы нескольких WAV, стабильность номера повторяющегося голоса.
- Подготовка настоящих WAV отдельных реплик для онлайн-распознавания без внешнего запроса.
- Добавление разметки старой встречи с сохранением предыдущего текста и конспекта без платных запросов.
- TXT с таймкодами и спикерами, HTTP-скачивание и соответствие реплик сохранённому JSON.
- Удаление исходного видео с сохранением текста; удаление встречи с сохранением журнала расходов.
- Восстановление прерванных операций, очистка временных файлов, блокировка второго сервера с тем же каталогом.
- Host/Origin, недоступность `.env` через HTTP, безопасное отображение HTML в имени файла.
- Структура конспекта, расчёт стоимости, кешированные токены, неизвестные тарифы, ошибки сети и повреждённые строки журнала.
- Интерфейс: переключение режима, настройки автозапуска, ручные кнопки, журнал, скачивание TXT и удаление. JavaScript-ошибок и горизонтального переполнения страницы не обнаружено.

На реальной двухминутной записи локальная обработка с определением спикеров заняла около 22 секунд на проверенном компьютере: 19 реплик и 2 автоматически выделенных голоса. Дополнительно проверена запись длительностью около 347 секунд, в том числе таймкоды после границы 300 секунд. Это измерение работы, а не оценка точности по ручной эталонной разметке и не гарантия скорости на другом компьютере.

Установщик моделей спикеров проверен повторным запуском с проверкой SHA-256. Синтаксис `server.mjs` и `public/app.js` проверен Node.js.

Реальное внешнее скачивание проверено на общедоступном MP4 `https://www.w3schools.com/html/mov_bbb.mp4`: 788 493 байта, длительность по FFprobe 10,027 с. Использовался рабочий HTTP-клиент с проверкой DNS и закреплением адреса; временный файл удалён. Это проверка прямой ссылки, а не совместимости со всеми облачными сервисами.

В интеграционном тесте успешного автоанализа скачивание подменено потоком настоящего видео, распознавание выполняется реальной локальной моделью, а ответ OpenAI — явно заданным тестовым ответом для проверки API-контракта. Это не подтверждает качество реального AI-конспекта; такой результат не попадает в рабочие данные или демонстрацию. Браузерный тест использует пустой ключ и проверяет автоматический переход к ожидаемой ошибке конспекта с сохранением настоящей расшифровки. Платных запросов при доработке не выполнялось.

## Дополнительные проверки на своих записях

Без API-запросов:

```powershell
npm run test:local -- "C:\Videos\встреча.mp4" "C:\Videos\встреча.webm"
```

С реальными запросами OpenAI, для записей длительностью 2–5 минут:

```powershell
npm run test:real -- "C:\Videos\встреча.mp4" "C:\Videos\встреча.webm"
```

Вторая команда читает `.env` и при наличии ключа расходует API-квоту. Без ключа проверяется только путь до распознавания и ожидаемая ошибка настройки. Платные запросы при последних доработках не выполнялись; успешный ответ онлайн-распознавания с новым делением на реплики и генерация конспекта этой проверкой не подтверждены.

## Артефакты и ограничения проверки

Отчёты, настоящие тексты и скриншоты создаются в `test-output/`, исключённом из Git. Для тестов используются временные каталоги и пустой API-ключ, кроме явно запускаемого `test:real`. Примеры для проверки форматирования, схемы и учёта расходов не подменяют реальное распознавание в приложении.

Точность каждого слова, разделения голосов, решений, исполнителей и сроков нужно сверять с записью вручную. Схема ответа проверяет структуру, а не достоверность. Проверки не имитируют физическое отключение питания или отказ накопителя; атомарная запись не заменяет резервные копии. Расчётная стоимость не сверена с реальным списанием провайдера.
