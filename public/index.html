Распознавание речи
Автозапуск для ручной загрузки Снимите флажок, чтобы запускать этап кнопкой в карточке встречи.

На Яндекс Диске выберите видео → «Поделиться» → «Скопировать ссылку». Откройте доступ к файлу по ссылке и разрешите скачивание. После получения файла распознавание и платный AI-анализ запустятся автоматически. Если Яндекс временно ограничит скачивание, повторите позже или загрузите файл вручную.

Прямая ссылка на MP4/WebM или публичная ссылка Google Drive. Скачивание должно быть доступно без входа и ручных подтверждений сервиса. После импорта автоматически запустятся распознавание и AI-анализ, независимо от флажков выше. Создание конспекта использует платный API OpenAI.

Перетащите видео сюда или выберите файл

WebM или MP4 · до 1 ГБ · до 30 минут

Исходное видео хранится на этом компьютере до удаления. Временное аудио удаляется после транскрибации.

Локальная модель недоступна. Файл можно загрузить, а для локальной транскрибации выполните npm run setup:local и перезапустите сервер. Автоматического переключения на онлайн нет.
Для конспекта нужен ключ OpenAI в .env. Локальная транскрибация работает без ключа. При ручной загрузке можно отключить автозапуск конспекта; импорт из облака всегда запускает AI-анализ.
